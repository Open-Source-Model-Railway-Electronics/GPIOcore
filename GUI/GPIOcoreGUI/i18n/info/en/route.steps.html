Route steps

A route is a list of things to do, from top to bottom. Each line (step) sets one output and then waits a moment before the next step.

When does the route start? When the button on the input pin is pressed, or when the command station sends any command (straight or curved) to the input's DCC address.

The columns

  • Output — what this step operates.
  • Value — what the output should do. This depends on the kind of output:
    • turnout, light, relay: curved (0) or straight (1);
    • 4-aspect signal: an aspect number (0–255) — the same number your command station uses;
    • servo: curved, straight, or an exact angle between 10° and 170°;
    • PWM: a brightness / speed value 0–255.
  • Wait after — how long to wait before the next step, in tenths of a second (0.3 s is the default, up to 1638 s ≈ 27 minutes). Coil turnouts drawing a lot of current at once can make your power supply dip: a short wait between them helps.

How to make one

  1. Choose an output in the first line, or drag an output onto this input in the middle of the screen.
  2. Click + Add step (or drag again) for the next one.
  3. Use ▲ ▼ to change the order, and the bin to delete a step.

The same output may appear more than once. Example: a servo that first goes to 45° and later to 135° for a slow, two-stage movement.

Older boards (protocol v1) only store 8 steps with curved / straight and a fixed 0.5 s.
