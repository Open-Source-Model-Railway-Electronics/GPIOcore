Toggle or absolute?

Toggle — every press switches the output over: straight → curved → straight …
Use this for a single push button (a button that springs back when you let go). The output changes at the moment you press, not when you let go.
With DCC every command for the address switches it over.

Absolute — the output follows the input, like a light switch.
Use this for a toggle switch (a switch that stays where you put it) or for DCC: the command station then says “straight” or “curved” and the output does exactly that.
With a switch: contact closed = state 0 (curved / off), contact open = state 1 (straight / on).

Not sure? Using DCC from a handheld or a computer program? Choose Absolute. One push button on a panel? Choose Toggle.
