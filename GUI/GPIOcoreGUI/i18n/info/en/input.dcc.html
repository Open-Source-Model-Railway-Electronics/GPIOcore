DCC accessory address

Your DCC command station (the digital system that drives your trains) can also send commands to accessories such as turnouts. Every accessory has a number: its address.

Tick this box and type the address you use on your handheld or in your computer program (for example 12). When the command station switches address 12, this input reacts as if its button was pressed.

  • For direct control: “straight” and “curved” from the command station set the output (Absolute), or every command switches it over (Toggle).
  • For a route: both “straight” and “curved” start the route.

Common mistake: two inputs with the same address both react. That can be on purpose, but usually it is a typo.

No DCC? Leave the box unticked and only use a pin.
