DCC accessory address

Your DCC command station can also send commands to accessories such as turnouts. Every accessory has a number: its address.

Tick this box and type the address you use on your handheld or in your computer program (for example 12). When the command station switches address 12, this input reacts.

  • Absolute: "straight" and "curved" set the output.
  • Toggle: every command switches the output over.
  • Route: any command, or only "straight" / only "curved" (see the route settings).

A command station sends each command a few times. A toggle input and a route take the first one and ignore the same address for half a second, so a toggle does not flip back.

Common mistake: two inputs with the same address both react. That can be on purpose (two routes on one address), but usually it is a typo.

No DCC? Leave the box unticked and only use a pin.
