Board link (TX): commands to other boards

Several boards work together over a chain of wires: TX (D1) of one board to RX (D0) of the next, with a common GND. A board that receives a command passes it on at once and runs it as if it came from the DCC command station: every input with that DCC address reacts as usual. The other boards need no setting: set them up as a normal DCC decoder.

  board 1 TX (D1) ----> board 2 RX (D0)
  board 2 TX (D1) ----> board 3 RX (D0)
  GND -------------------- GND
  • One board link output is enough. Put it in a route; each step chooses the address (1-255) and Curved or Straight (a turnout command), or Value 0-255 (DCC extended: an aspect, a servo angle, PWM, a sound track).
  • Example: a route on board 1 with steps #5 straight, #9 curved, #20 value 1. On board 2 an absolute input with DCC address 5 sets its servo straight, one with address 9 curved, and a signal on address 20 shows aspect 1.
  • The wait time between the steps is also the time between the commands, so the turnouts move one after another.
  • Own address: switched on or off directly (a toggle or absolute input, DCC), the output sends its own address, curved or straight. Leave it at none when you only use it in routes.
  • Only without a PC. With the program connected the serial line is the program's: nothing is sent or passed on. On the layout the link starts 5 seconds after power-up.
  • A DFPlayer can stay on the same TX line; it ignores these commands.
  • Not on a DCCnext: it has no D1 on its terminals.
