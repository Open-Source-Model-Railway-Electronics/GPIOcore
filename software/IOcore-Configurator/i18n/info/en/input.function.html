What does this input do?

An input is something that gives the board a command. Choose what should happen:

  • Direct control — the input operates one output. Example: one push button on your control panel for one turnout. Press it, the turnout moves.
  • Route — the input sets several outputs, one after the other. Example: one button for “track 3 into the station”: turnout 1 straight, turnout 2 curved, signal to green. Up to 16 steps.
  • Sensor (occupancy) — an occupancy detector or other sensor. It switches nothing itself; a block signal or a servo used as a semaphore arm reads it to see whether its block is occupied.
  • Not in use — the input does nothing. Use this for inputs you do not need.

Tip: you do not have to choose here first. Dragging an output onto an unused input makes it “Direct control” automatically.
