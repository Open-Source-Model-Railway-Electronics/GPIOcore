Eigene Werte: mehr als ein und aus

Normalerweise schaltet ein Eingang mit Umschalten oder Absolut seinen Ausgang auf Abzweig / aus (0) oder Gerade / ein (1). Mit Eigene Werte sendet stattdessen jeder der beiden Zustände seinen eigenen Wert, genau wie ein Fahrstraßen-Schritt:

  • Servo — ein Winkel, z. B. aus = 45°, ein = 135° (oder wie üblich Abzweig / Gerade).
  • 4-begriffiges Signal — ein Signalbild pro Zustand, Lampe für Lampe gewählt mit ▾.
  • PWM — eine Helligkeit pro Zustand, z. B. aus = 20 (gedimmt), ein = 255.
  • Soundeffekt — ein Titel pro Zustand; Stopp (0) beendet die Wiedergabe. Ein Sound-Ausgang kann viele Titel abspielen, jeden gewählt von seinem eigenen Eingang.
  • Andere Ausgänge — Abzweig oder Gerade pro Zustand, zum Beispiel andersherum.

Aus / Abzweig wird verwendet, wenn der Zustand des Eingangs 0 wird (ein absoluter Eingang: Taster gedrückt oder ein DCC-Befehl 'Abzweig'), Ein / Gerade, wenn er 1 wird. Ein Eingang mit Umschalten wechselt zwischen beiden.

Die beiden Werte werden als 2 Schritte im Fahrstraßen-Speicher des Eingangs abgelegt, sie zählen also zur Fahrstraßen-Summe der Platine. DCC-extended-Befehle senden weiterhin ihren eigenen Wert.

Verbinden Sie einen Eingang mit einem Sound-Ausgang, werden eigene Werte von selbst eingeschaltet: aus = Stopp, ein = Titel 1.
