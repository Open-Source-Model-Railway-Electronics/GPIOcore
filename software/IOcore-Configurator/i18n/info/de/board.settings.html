Platineneinstellungen

  • Name: bis zu 16 Zeichen, auf der Platine gespeichert. Über diesen Namen findet das Programm die Datei dieser Platine (Namen der Eingänge und Ausgänge), geben Sie also jeder Platine einen eigenen Namen.
  • Platinentyp: Arduino Nano, DCCnext oder Jack of all trades. Er bestimmt, welche Pins es gibt.
  • Eigene Wartezeit pro Fahrstraßen-Schritt (ab Stufe Fortgeschritten): aus = jeder Schritt wartet gleich lange (unten einstellbar) und Fahrstraßen brauchen nur halb so viel Speicher. Ein = jeder Schritt hat seine eigene Wartezeit.
  • Fahrstraßen-Verriegelung (ab Stufe Fortgeschritten): was passiert, wenn eine Fahrstraße gestartet wird, während eine andere noch läuft. Aus = beide laufen, ein = die zweite wird ignoriert, automatisch = Fahrstraßen, die eine Weiche stellen, laufen nacheinander, Fahrstraßen nur mit Beleuchtung dürfen gleichzeitig laufen.

Pins mit fester Aufgabe auf jeder Platine: D2 (DCC-Eingang und Konfig-Taster), D13 (Konfig-LED) und D0 / D1 (die serielle Leitung).
