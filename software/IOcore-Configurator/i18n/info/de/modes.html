Konfigurieren, Simulieren und Live-Test

Das Programm ist immer in einem von drei Modi: die farbigen Knöpfe oben. Die Verbindung ist davon getrennt: Verbinden / Trennen neben dem Port, mit dem Zustand daneben (Offline, Verbunden: Name, Simulation).

ModusRahmenWas Sie tun können
● Konfigurierenkeiner offline, rot wenn verbundenAlles ändern. Offline bereiten Sie eine Platine vor; verbunden geht jede Änderung sofort an die Platine. Von der Platine wird nichts automatisch gelesen: Verwenden Sie Platine lesen oder Alles schreiben.
● SimulierengelbIhre Konfiguration läuft auf einer simulierten Platine. Drücken Sie die Tasten der Eingänge und beobachten Sie; nichts kann geändert werden.
● Live-Testgrün wenn verbundenVerbindet sich selbst. Drücken Sie die Tasten der Eingänge und sehen Sie, was die echte Platine tut; nichts kann geändert werden. Hat die Platine einen anderen Namen als der Bildschirm, bietet das Programm an, zuerst die Platine zu lesen.

Nichts wird von selbst in einer Datei gespeichert: Speichern (Ctrl+S) fragt immer nach dem Ort, und beim Schließen fragt das Programm nach ungespeicherten Änderungen.

Die Tasten der Eingänge

  • ◀ / ▶ (absolute Eingänge): ◀ = Abzweig / aus, ▶ = Gerade / ein.
  • ▶ drücken (Umschalten) und ▶ Start (Fahrstraße): wie ein Tastendruck oder ein DCC-Befehl.
  • Signalbild ▾ / Wert ▾: für einen Eingang, der ein Signal oder einen PWM-Ausgang steuert. Wählen Sie pro Lampe aus, ein, blinkend oder gegenphasig blinkend.

Eine Taste wirkt wie ein DCC-Befehl: Ein zweiter Klick innerhalb einer halben Sekunde wird ignoriert, genau wie ein wiederholtes Paket einer Zentrale.

Beim Simulieren wirkt ein Eingang mit Pin (nicht analog) auf diesen Pin, wie der echte Taster oder Schalter: ▶ drücken / ▶ Start zieht den Pin auf low und lässt ihn wieder los, ◀ hält den Pin eines absoluten Eingangs auf low und ▶ auf high (die gehaltene Seite ist hervorgehoben). So reagiert auch alles, was den Pin liest, zum Beispiel ein Servo, der dem Eingang als Melder folgt. Eingänge ohne Pin wirken wie ein DCC-Befehl.

Was die Ausgänge zeigen

  • Blauer Punkt = Gerade / ein, roter Punkt = Abzweig / aus, grau = noch unbekannt.
  • Servo: eine Skala mit dem Winkel; sie dreht sich Grad für Grad mit, so wie die Platine ihn meldet.
  • Signal: vier Lampen in ihren Farben, blinkend wie auf der Platine.
  • Herzstück-Relais: eine kleine Relaiszeichnung. Der Kontaktarm und das Herzstück zeigen, welcher Kontakt Spannung führt (rot = Abzweig, blau = Gerade). Ein Electrofrog ist grau (stromlos), während die Weiche umläuft; ein Unifrog schaltet sofort um.

Für einen Live-Test muss nichts an der Platine angeschlossen sein: Sie sehen, was die Platine schalten würde.
