Bluetooth (HC-05)

Avec un module Bluetooth HC-05 sur la carte, vous pouvez la configurer sans câble USB. Le programme configure le module pour vous à travers la carte (Carte > Configurer le Bluetooth (HC-05), niveau Avancé ou plus). Arduino Nano uniquement : il vous faut le bouton de config pour vous connecter ensuite.

Câblage (HC-05 → Nano) :

  • VCC → 5 V, GND → GND.
  • RXD → D1 via un pont diviseur : 1 kΩ de D1 vers RXD, 2 kΩ de RXD vers GND (le HC-05 attend 3,3 V sur son RXD).
  • TXD → D0 via une diode Schottky (BAT85 ou 1N5819), avec la cathode (l'anneau) côté TXD du HC-05. La diode permet au HC-05 de tirer D0 au niveau bas sans jamais s'opposer à la puce USB : l'USB continue donc de fonctionner pendant que le HC-05 est branché.

Configuration (une seule fois) :

  1. Maintenez le bouton du HC-05 enfoncé pendant que vous branchez le câble USB. Sa LED clignote maintenant lentement (environ toutes les 2 secondes) : le module est en mode AT.
  2. Connectez le programme à la carte par USB.
  3. Choisissez Carte > Configurer le Bluetooth (HC-05) et cliquez sur Démarrer. La carte essaie les vitesses habituelles et règle le module sur 115200 bauds et le nom IOcore-<nom de la carte>. Le code PIN reste inchangé. Cela prend quelques secondes.
  4. Débranchez la carte et rebranchez-la, sans maintenir le bouton.
  5. Dans les paramètres Bluetooth de Windows, associez IOcore… (code PIN 1234, ou 0000 sur certains modules). Windows crée un port COM pour lui (parfois deux : prenez le port « sortant »). Choisissez ce port dans IOcore.

En cas d'échec : le module n'est pas en mode AT (clignotement rapide = mode normal), le câblage est faux, ou la diode manque ou est montée à l'envers. D'autres modules (HC-06, certains clones) ne connaissent pas ces commandes.

Connexion par Bluetooth : l'ouverture du port COM Bluetooth ne réinitialise pas la carte, et 5 secondes après le démarrage la ligne série est devenue la liaison entre cartes. Quand vous cliquez donc sur Connecter, le programme affiche « En attente de la carte — appuyez brièvement sur son bouton de config ». Appuyez brièvement sur le bouton de config (D2) : la carte rend la ligne au programme pendant 5 secondes et s'annonce, et le programme se connecte. Le programme attend cela jusqu'à 30 secondes.

Une carte équipée d'un HC-05 ne peut pas utiliser la liaison entre cartes en même temps : toutes deux ont besoin de D0 / D1.
