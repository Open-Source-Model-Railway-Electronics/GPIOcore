Pines D0 y D1

D0 y D1 son los cables por los que el Arduino habla con este programa a través del USB. Las placas más nuevas pueden usarlos igualmente para su maqueta:

  • Al arrancar, la placa espera 5 segundos a este programa.
  • Si el programa se conecta, D0 / D1 quedan reservados para el USB mientras configura. Lo que esté conectado a esos pines no funciona entonces.
  • Si no se conecta nada (uso normal en la maqueta), D0 / D1 pasan a ser pines normales.

Úselos para cosas sencillas como LED. Evite cargas grandes en D0: pueden interferir al cargar un firmware nuevo.
