Retroalimentación — un sensor que espera el grabador

Una entrada de retroalimentación es un sensor de vía: un contacto reed bajo la vía con un imán bajo el tren, una barrera de luz o un detector de consumo. Le dice a la placa: “aquí hay un tren”.

¿Por qué? Los trenes no tardan siempre exactamente lo mismo. Al grabar, se guarda el momento en que actúa el sensor. Al reproducir, la placa se detiene en ese punto y espera hasta que el sensor vuelva a actuar. Así es el tren quien marca el ritmo, no un reloj.

Id de retroalimentación: un número (0–15) para distinguir los sensores. Dé a cada sensor su propio número.

Conéctelo como un pulsador: sensor entre el pin y GND.
