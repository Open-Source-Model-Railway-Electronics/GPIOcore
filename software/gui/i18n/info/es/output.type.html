¿Qué hay conectado a esta salida?

  • Simple fijo — un pin encendido o apagado. LED, un módulo de relé, lámparas (a través de un transistor o un relé).
  • Simple pulso — un pin recibe un pulso corto. Para un desenganchador o un aparato de una bobina.
  • Simple intermitente — un pin parpadea mientras está activado. Una luz de aviso.
  • Doble fijo — dos pines: A encendido y B apagado, o al revés. Señales de dos colores, dos relés.
  • Doble pulso — dos pines, uno de ellos recibe un pulso corto. Para motores de desvío de bobinas (Peco, Roco, Fleischmann …): A = una bobina, B = la otra bobina.
  • Doble intermitente — dos pines parpadean alternativamente.
  • Luz alterna — dos luces por turnos con una pausa: luces de paso a nivel.
  • Chimenea / tubo fluorescente / soldador — efectos de luz: fuego que parpadea, un tubo fluorescente que se enciende parpadeando, destellos de soldadura. (Chimenea y tubo fluorescente necesitan pines PWM.)
  • Señal de 4 aspectos — cuatro LED (verde, amarillo, rojo, blanco …), puestos por órdenes de señal DCC o por un itinerario.
  • Servo — un servo de modelismo como motor de desvío. Movimiento lento y realista.
  • PWM — un brillo para una lámpara o una tira de LED, opcionalmente con un fundido lento (día y noche).
  • Señal de bloqueo — una señal automática (lámparas A–D): la placa elige el aspecto por sí misma a partir de los detectores de su propio cantón y del siguiente.
  • Efecto de sonido — un reproductor MP3 (DFPlayer Mini) en D1: una campana, un silbato, un anuncio. La entrada elige la pista. Solo suena cuando no hay ningún PC conectado.
  • Sin uso — no hay nada conectado.

Importante con bobinas: un pin de Arduino no puede accionar una bobina directamente. Use una placa de potencia (por ejemplo un ULN2803 o un módulo MOSFET) entre el pin y la bobina.
