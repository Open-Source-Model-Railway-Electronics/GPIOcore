Läge och test

Varje utgång har ett läge: 0 eller 1. Vad det betyder beror på utgången: för en växel 0 = avvikande och 1 = rakt; för en belysning 0 = av och 1 = på.

Sparat läge: kortet kommer ihåg det senaste läget, även när strömmen är av. Efter påslag går utgången tillbaka till det (utom spolväxlar: de får ingen puls vid start, så att de inte alla slår om samtidigt).

▶ Test: avvikande / av och ▶ Test: rakt / på skickar den här utgången till kortet direkt och ställer om den. Använd detta för att kontrollera kopplingen: lägger rätt växel om, åt rätt håll? Om “rakt” och “avvikande” är omkastade, byt plats på de två lägena (servo) eller de två trådarna / pinnarna (spolmotor).
