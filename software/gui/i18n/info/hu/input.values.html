Saját értékek: több mint be és ki

Normál esetben egy váltás vagy abszolút típusú bemenet a kimenetét kitérő irány / ki (0) vagy egyenes / be (1) állapotba kapcsolja. A Saját értékek beállítással a két állapot mindegyike saját értéket küld helyette, pontosan úgy, mint egy vágányút-lépés:

  • Szervó — egy szög, pl. ki = 45°, be = 135° (vagy a szokásos kitérő irány / egyenes).
  • 4 jelzési képes jelző — állapotonként egy jelzési kép, lámpánként kiválasztva a ▾ gombbal.
  • PWM — állapotonként egy fényerő, pl. ki = 20 (tompított), be = 255.
  • Hangeffekt — állapotonként egy szám; a leállítás (0) leállítja a lejátszást. Egy hangkimenet sok számot játszhat le, mindegyiket a saját bemenete választja ki.
  • Egyéb kimenetek — állapotonként kitérő irány vagy egyenes, például fordítva.

A Ki / kitérő irány akkor érvényes, amikor a bemenet állapota 0 lesz (abszolút bemenetnél: lenyomott gomb vagy DCC 'kitérő irány' parancs), a Be / egyenes, amikor 1 lesz. A váltás típusú bemenet a kettő között vált.

A két érték 2 lépésként tárolódik a bemenet vágányút-memóriájában, így beleszámít a panel összes vágányút-lépésébe. A DCC extended parancsok továbbra is a saját értéküket küldik.

Ha egy bemenetet hangkimenetre köt, a saját értékek maguktól bekapcsolnak: ki = leállítás, be = 1. szám.
