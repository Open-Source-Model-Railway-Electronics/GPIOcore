Konfigurace, simulace a živý test

Program je vždy v jednom ze tří režimů: barevná tlačítka nahoře. Připojení je samostatné: Připojit / Odpojit vedle portu, se stavem zobrazeným vedle (Offline, Připojeno: název, Simulace).

RežimRámečekCo můžete dělat
● Konfigurovatžádný offline, červený při připojeníMěnit vše. Offline připravujete desku; při připojení jde každá změna do desky okamžitě. Nic se nenačítá z desky automaticky: použijte Načíst desku nebo Zapsat vše.
● SimulovatžlutýVaše konfigurace běží na simulované desce. Mačkejte tlačítka vstupů a sledujte; nic nelze změnit.
● Živý testzelený při připojeníPřipojí se sám. Mačkejte tlačítka vstupů a sledujte, co dělá skutečná deska; nic nelze změnit. Pokud má deska jiný název než obrazovka, program nabídne nejprve desku načíst.

Nic se do souboru neukládá samo: Uložit (Ctrl+S) se vždy zeptá kam a při zavírání se program zeptá na neuložené změny.

Tlačítka vstupů

  • ◀ / ▶ (absolutní vstupy): ◀ = do odbočky / vyp, ▶ = přímo / zap.
  • ▶ stisk (přepínání) a ▶ start (jízdní cesta): jako stisk tlačítka nebo odeslání DCC povelu.
  • návěst ▾ / hodnota ▾: pro vstup, který řídí návěstidlo nebo PWM výstup. Pro každé světlo zvolte vyp, zap, bliká nebo bliká v protifázi.

Tlačítko se chová jako DCC povel: druhé kliknutí do půl sekundy se ignoruje, stejně jako opakovaný paket z centrály.

V režimu Simulovat funguje vstup s pinem (ne analogovým) na tomto pinu jako skutečné tlačítko nebo přepínač: ▶ stisk / ▶ start stáhne pin do nízké úrovně a zase ho uvolní, ◀ drží pin absolutního vstupu v nízké úrovni a ▶ ve vysoké (držená strana je zvýrazněna). Reaguje tak i vše, co tento pin čte, například servo, které sleduje vstup jako hlásič. Vstupy bez pinu se chovají jako DCC povel.

Co ukazují výstupy

  • Modrá tečka = přímo / zap, červená tečka = do odbočky / vyp, šedá = zatím neznámo.
  • Servo: ciferník s úhlem; otáčí se stupeň po stupni, jak ho deska hlásí.
  • Návěstidlo: čtyři světla ve svých barvách, blikající jako na desce.
  • Relé srdcovky: malý nákres relé. Přepínací kontakt a srdcovka ukazují, který kontakt je pod napětím (červená = do odbočky, modrá = přímo). Electrofrog je šedý (bez napětí), zatímco se výhybka přestavuje; unifrog se přepne okamžitě.

Pro živý test nemusí být k desce nic připojeno: vidíte, co by deska přepnula.
