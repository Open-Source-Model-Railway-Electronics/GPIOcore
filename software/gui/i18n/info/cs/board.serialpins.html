Piny D0 a D1

D0 a D1 jsou vodiče, kterými Arduino komunikuje s tímto programem přes USB. Novější desky je přesto mohou využít pro kolejiště:

  • Po startu deska čeká 5 sekund na tento program.
  • Pokud se program připojí, D0 / D1 zůstanou během konfigurace vyhrazeny pro USB. Věci na těchto pinech pak nefungují.
  • Pokud se nic nepřipojí (normální provoz na kolejišti), stanou se z D0 / D1 běžné piny. Když na D0 / D1 nic není (žádný vstup ani výstup, žádný zvukový efekt), zůstanou vodiči USB: program se může připojit kdykoli.
  • Krátký stisk tlačítka konfigurace (Nano) z nich na 5 sekund opět udělá vodiče USB, takže se program může připojit bez resetu.

Používejte je pro jednoduché věci, jako jsou LED. Nepřipojujte na D0 velkou zátěž: může rušit nahrávání nového firmwaru.
