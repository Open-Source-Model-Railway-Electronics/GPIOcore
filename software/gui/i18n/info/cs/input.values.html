Vlastní hodnoty: víc než zap a vyp

Normálně vstup typu Přepínání nebo Absolutní přepíná svůj výstup na do odbočky / vyp (0) nebo přímo / zap (1). S volbou Vlastní hodnoty posílá každý z obou stavů místo toho vlastní hodnotu, stejně jako krok jízdní cesty:

  • Servo — úhel, např. vyp = 45°, zap = 135° (nebo jako obvykle do odbočky / přímo).
  • Návěstidlo se 4 návěstmi — návěst pro každý stav, volená světlo po světle pomocí ▾.
  • PWM — jas pro každý stav, např. vyp = 20 (ztlumeno), zap = 255.
  • Zvukový efekt — skladba pro každý stav; stop (0) zastaví přehrávání. Jeden zvukový výstup může přehrávat mnoho skladeb, každou zvolenou vlastním vstupem.
  • Ostatní výstupy — do odbočky nebo přímo pro každý stav, například obráceně.

Vyp / do odbočky se použije, když stav vstupu přejde na 0 (absolutní vstup: tlačítko stisknuto nebo DCC povel „do odbočky“), Zap / přímo, když přejde na 1. Vstup typu Přepínání je střídá.

Obě hodnoty se ukládají jako 2 kroky v paměti jízdní cesty vstupu, takže se započítávají do celkového počtu kroků jízdních cest desky. Povely DCC extended dál posílají svou vlastní hodnotu.

Připojte vstup ke zvukovému výstupu a vlastní hodnoty se zapnou samy: vyp = stop, zap = skladba 1.
