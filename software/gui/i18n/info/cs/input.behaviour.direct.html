Přepínání, nebo absolutní?

Přepínání — každý stisk přepne výstup: přímo → do odbočky → přímo …
Použijte pro jedno tlačítko (které se po puštění samo vrátí). Výstup se změní v okamžiku stisku, ne při puštění.
U DCC každý povel pro tuto adresu výstup přepne.

Absolutní — výstup sleduje vstup, jako vypínač světla.
Použijte pro přepínač (který zůstane tam, kam ho dáte) nebo pro DCC: centrála pak řekne „přímo“ nebo „do odbočky“ a výstup udělá přesně to.
S přepínačem: kontakt sepnutý = stav 0 (do odbočky / vyp), kontakt rozepnutý = stav 1 (přímo / zap). Přepínač přestavený při vypnutém napájení se při startu respektuje. Vstup typu Přepínání při startu nedělá nic.

Nejste si jistí? Používáte DCC z ručního ovladače nebo počítačového programu? Zvolte Absolutní. Jedno tlačítko na panelu? Zvolte Přepínání.
