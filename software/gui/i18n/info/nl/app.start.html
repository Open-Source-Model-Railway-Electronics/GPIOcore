Aan de slag

Dit programma stelt een GPIOcore-print in: een kleine Arduino (Nano / Uno, of een DCCnext) die onder je baan zit en dingen schakelt: wissels, verlichting, seinen, relais. Je vertelt de print wat er op welke pin is aangesloten, en waardoor het moet bewegen.

De twee soorten

  • Uitgangen (rechterkolom) zijn dingen die de print doet: een servo bewegen, een wisselspoel een puls geven, een LED laten branden, een relais schakelen. Er zijn er 16.
  • Ingangen (linkerkolom) zijn dingen die de print opdracht geven: een drukknop op je bedieningspaneel, of een commando van je DCC-centrale (je digitale systeem / handregelaar). Er zijn er 16.

Stap voor stap

  1. Verbinden. Steek de print in de USB-poort. Kies bovenaan de poort (meestal staat er CH340, USB Serial of Arduino bij) en klik op Verbinden. Geen print bij de hand? Klik op Demo om alles te proberen met een nagebootste print.
  2. Een uitgang instellen. Klik rechts op een uitgang. Er schuift een paneel in vanaf rechts. Kies het type (bijvoorbeeld Servo) en de pin waar de draad op zit.
  3. Een ingang instellen. Klik links op een ingang. Er schuift een paneel in vanaf links. Kies waardoor hij start: een knop-pin, een DCC-adres, of allebei.
  4. Verbind ze. Sleep de uitgang (rechts) naar de ingang (links). Er verschijnt een gekleurde lijn: die ingang bedient nu die uitgang. De uitgang krijgt de kleur van zijn ingang, zodat je in één oogopslag ziet wat bij elkaar hoort.
  5. Naar de print sturen. Alles wat je hebt veranderd krijgt een oranje stip. Klik bovenaan op … wijziging(en) schrijven. De print bewaart het, ook als de stroom eraf is.

Goed om te weten

  • Elk (i)-knopje legt uit wat ernaast staat. Klik erop als je twijfelt.
  • Rode tekst betekent dat er iets mis is, bijvoorbeeld twee dingen op dezelfde pin.
  • Test stand 0 / 1 in een uitgangspaneel laat hem meteen bewegen, zo kun je je bedrading controleren.
  • Bestand → Configuratie opslaan bewaart een kopie van je instellingen op de computer. Doe dit voordat je gaat experimenteren.
  • Er een rommeltje van gemaakt? Terugdraaien gooit alles weg wat je nog niet naar de print hebt geschreven.
