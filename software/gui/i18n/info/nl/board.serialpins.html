Pinnen D0 en D1

D0 en D1 zijn de draden waarmee de Arduino via USB met dit programma praat. Nieuwere printen kunnen ze toch voor je baan gebruiken:

  • Als de print opstart, wacht hij 5 seconden op dit programma.
  • Als het programma verbindt, blijven D0 / D1 gereserveerd voor USB zolang je instelt. Wat op die pinnen zit werkt dan niet.
  • Als er niets verbindt (normaal gebruik op de baan), worden D0 / D1 gewone pinnen.

Gebruik ze voor eenvoudige dingen zoals LED's. Zet geen zware belasting op D0: dat kan het uploaden van nieuwe firmware verstoren.
