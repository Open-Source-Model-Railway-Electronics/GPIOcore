Bouton de config (D2) et apprentissage des servos avec votre régulateur

Sans ordinateur, vous pouvez régler les positions de fin de course des servos avec le bouton de config et votre régulateur DCC.

Câblage : un bouton-poussoir de D2 vers GND. D2 est aussi l'entrée DCC : le DCC change tout le temps son niveau, un bouton enfoncé le maintient au niveau bas, et c'est ce que la carte détecte (1 ms au niveau bas sans interruption). Une LED avec résistance sur D13 indique le mode (la plupart des Arduino en ont déjà une).

  1. Maintenez le bouton de config 2 secondes : la LED se met à clignoter. Vous êtes en mode configuration.
  2. Appuyez brièvement : le servo suivant est sélectionné et bascule, pour que vous voyiez lequel c'est. Appuyez encore pour le servo suivant.
  3. Sur votre régulateur, sélectionnez l'adresse de loco 9999.
    • Tournez le bouton de vitesse : le servo sélectionné bouge. Le sens de marche décide de quel côté, le bouton à quelle vitesse.
    • F1 = mémoriser cet angle comme dévié, F2 = le mémoriser comme direct.
    • F3 = faire basculer le servo (pour vérifier), F5 = servo suivant.
    • F4 = inverser les relais du cœur du servo sélectionné, pour les modules relais actifs sur LOW. Chaque appui bascule entre normal et inversé.
  4. Maintenez de nouveau le bouton de config 2 secondes : la LED reste allumée. Retour au fonctionnement normal.

Les nouvelles positions sont mémorisées tout de suite. Quand vous connectez le programme plus tard, il les relit.

Appui bref hors du mode configuration = mode GUI. 5 secondes après le démarrage sans programme, la ligne série devient la liaison entre cartes. Un appui bref sur le bouton de config (LED fixe, pas en mode configuration) la rend au programme pendant 5 secondes et la carte s'annonce, pour que le programme puisse se connecter sans reset, par exemple via Bluetooth (voir Aide > Bluetooth (HC-05)). Quand le programme affiche « En attente de la carte », c'est le moment d'appuyer.

C'est pourquoi D2 et D13 ne peuvent jamais servir d'entrées ou de sorties.
