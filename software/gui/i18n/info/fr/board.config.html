Bouton de config (A7) et apprentissage des servos avec votre régulateur

Sans ordinateur, vous pouvez régler les positions de fin de course des servos avec le bouton de config et votre régulateur DCC.

Remarque : le bouton de config (A7) n'existe que sur un Arduino Nano. Un DCCnext n'a pas de A7, donc pas de bouton de config : réglez plutôt les positions de fin de course des servos dans le programme (ou avec la télécommande sur téléphone).

Câblage : un bouton-poussoir de A7 vers GND, plus une résistance de 10 kΩ de A7 vers 5 V (A7 n'a pas de pull-up interne). Une LED avec résistance sur D13 indique le mode (la plupart des Arduino en ont déjà une).

  1. Maintenez le bouton de config 2 secondes : la LED se met à clignoter. Vous êtes en mode configuration.
  2. Appuyez brièvement : le servo suivant est sélectionné et bascule, pour que vous voyiez lequel c'est. Appuyez encore pour le servo suivant.
  3. Sur votre régulateur, sélectionnez l'adresse de loco 9999.
    • Tournez le bouton de vitesse : le servo sélectionné bouge. Le sens de marche décide de quel côté, le bouton à quelle vitesse.
    • F1 = mémoriser cet angle comme dévié, F2 = le mémoriser comme direct.
    • F3 = faire basculer le servo (pour vérifier), F5 = servo suivant.
    • F4 = inverser les relais du cœur du servo sélectionné, pour les modules relais actifs sur LOW. Chaque appui bascule entre normal et inversé.
  4. Maintenez de nouveau le bouton de config 2 secondes : la LED reste allumée. Retour au fonctionnement normal.

Les nouvelles positions sont mémorisées tout de suite. Quand vous connectez le programme plus tard, il les relit.

Appui bref hors du mode configuration = mode GUI. 5 secondes après le démarrage, la carte ferme son port série si aucun programme ne s'est connecté et que la configuration utilise D0 ou D1 (elles deviennent des broches normales ; sinon le port reste ouvert). Un appui bref sur le bouton de config (LED fixe, pas en mode configuration) le rouvre pendant 5 secondes et la carte s'annonce, pour que le programme puisse se connecter sans reset, par exemple via Bluetooth (voir Aide > Bluetooth (HC-05)). Quand le programme affiche « En attente de la carte », c'est le moment d'appuyer.

C'est pourquoi D13 et A7 ne peuvent jamais servir d'entrées ou de sorties.
