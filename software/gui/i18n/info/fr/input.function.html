Que fait cette entrée ?

Une entrée est quelque chose qui donne un ordre à la carte. Choisissez ce qui doit se passer :

  • Commande directe — l'entrée commande une sortie. Exemple : un bouton-poussoir sur votre TCO pour un aiguillage. Vous appuyez, l'aiguillage bascule.
  • Itinéraire — l'entrée positionne plusieurs sorties, l'une après l'autre. Exemple : un bouton pour « voie 3 vers la gare » : aiguillage 1 direct, aiguillage 2 dévié, signal au vert. Jusqu'à 16 étapes.
  • Enregistreur — un bouton spécial qui enregistre ce que vous faites et le rejoue. Un seul par carte. Voir le (i) à côté de « Enregistreur » pour les détails.
  • Rétrosignalisation — un capteur de voie qu'une séquence enregistrée peut attendre. Voir le (i) à côté de « Id de rétrosignalisation ».
  • Non utilisé — l'entrée ne fait rien. Utilisez-le pour les entrées dont vous n'avez pas besoin.

Astuce : inutile de choisir ici d'abord. Glisser une sortie sur une entrée non utilisée la met automatiquement en « Commande directe ».
