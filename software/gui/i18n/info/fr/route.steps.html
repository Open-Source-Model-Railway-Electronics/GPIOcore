Étapes de l'itinéraire

Un itinéraire est une liste d'actions, de haut en bas. Chaque ligne (étape) positionne une sortie puis attend un moment avant l'étape suivante.

Quand l'itinéraire démarre-t-il ?

Quand le bouton sur la broche d'entrée est appuyé, ou sur une commande DCC pour l'adresse de l'entrée. Choisissez quelle commande DCC sous L'itinéraire démarre sur :

  • toute commande : direct et dévié le lancent tous les deux ;
  • direct seulement ou dévié seulement : ainsi deux itinéraires peuvent partager une adresse. Exemple, un passage à niveau sur l'adresse 1 : l'itinéraire A sur dévié seulement allume les feux et ferme les barrières, l'itinéraire B sur direct seulement les rouvre.

Une centrale répète une commande plusieurs fois ; l'itinéraire prend la première.

Les colonnes

  • Sortie : ce que commande cette étape.
  • Valeur : ce que la sortie doit faire :
    • aiguillage, lampe, relais : dévié (0) ou direct (1) ;
    • signal 4 feux : un numéro d'aspect (0–255) ;
    • servo : dévié, direct, ou un angle précis entre 10° et 170° ;
    • PWM : une valeur de luminosité / vitesse de 0–255.
  • Attente après : seulement si Temporisation propre à chaque étape d'itinéraire est activée dans les paramètres de la carte ; sinon chaque étape attend le temps fixe de la carte (0,3 s par défaut).

Comment en créer un

  1. Choisissez une sortie dans la première ligne, ou glissez une sortie sur cette entrée.
  2. Cliquez sur + Ajouter une étape (ou glissez de nouveau) pour la suivante.
  3. Utilisez ▲ ▼ pour changer l'ordre, et la corbeille pour supprimer une étape.

La même sortie peut apparaître plusieurs fois, par exemple un servo qui va d'abord à 45° puis à 135°.
