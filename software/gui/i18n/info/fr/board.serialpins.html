Broches D0 et D1

D0 et D1 sont les fils par lesquels l'Arduino parle à ce programme via l'USB. Les cartes récentes peuvent quand même les utiliser pour votre réseau :

  • Au démarrage, la carte attend ce programme pendant 5 secondes.
  • Si le programme se connecte, D0 / D1 restent réservées à l'USB pendant la configuration. Ce qui est branché sur ces broches ne fonctionne pas à ce moment-là.
  • Si rien ne se connecte (utilisation normale sur le réseau), D0 / D1 deviennent des broches normales. Quand rien n'est sur D0 / D1 (ni entrée ni sortie, ni effet sonore), elles restent des fils USB : le programme peut se connecter à tout moment.
  • Un appui bref sur le bouton de config (Nano) en refait des fils USB pendant 5 secondes, pour que le programme puisse se connecter sans reset.

Utilisez-les pour des choses simples comme des LED. Évitez les charges lourdes sur D0 : elles peuvent perturber le téléversement d'un nouveau firmware.
