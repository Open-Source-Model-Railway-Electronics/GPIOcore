Aggiornare il firmware

Il firmware è il programma che gira sull'Arduino della tua scheda IOcore. A volte c'è una versione più recente con correzioni o nuove funzioni. Questa finestra la carica sulla tua scheda.

Passo dopo passo

  1. Collega la scheda con un cavo USB.
  2. Porta: scegli la scheda. Di solito c'è scritto CH340, USB Serial o Arduino. Non la vedi? Controlla il cavo e clicca Aggiorna.
  3. File firmware: è il file con il nuovo programma (termina con .hex). Di solito il file giusto è già inserito. Altrimenti clicca Sfoglia… e scegli IOcore.hex.
  4. Tipo di scheda: la maggior parte delle schede funziona con Arduino Uno / Nano (bootloader nuovo). I Nano più economici o vecchi spesso richiedono Arduino Nano (bootloader vecchio). Non sei sicuro? Comincia dal primo: se la scheda non risponde, il programma prova da solo l'altro.
  5. Clicca Flash e aspetta che la barra sia piena. Ci vogliono circa 10-30 secondi. Non scollegare la scheda mentre è occupata.

Buono a sapersi

  • Questo programma rilascia la scheda durante il caricamento e poi si ricollega. Non devi fare niente.
  • Le impostazioni sulla scheda (uscite, ingressi, collegamenti) di solito vengono mantenute. Per sicurezza usa prima File → Salva configurazione.
  • Gli altri programmi che usano la scheda, come il monitor seriale dell'IDE Arduino, devono prima essere chiusi.
  • Qualcosa è andato storto? Leggi il messaggio rosso: dice cosa provare. Mostra dettagli mostra il rapporto completo, utile se chiedi aiuto a qualcuno.
  • Un caricamento fallito non rovina la scheda. Riprova semplicemente.

Tramite programmatore ArduinoISP (avanzato)

Solo per schede senza bootloader USB, o una scheda che non risponde più. Ti serve un secondo Arduino con lo sketch ArduinoISP, collegato ai sei pin ICSP della tua scheda. Scegli la porta di quell'Arduino programmatore. Questo imposta anche le impostazioni del chip (fuse) e rimuove il bootloader USB, quindi in seguito potrai aggiornare questa scheda solo con il programmatore. Cancella anche le tue impostazioni sulla scheda: salvale prima con File → Salva configurazione e riscrivile dopo.
