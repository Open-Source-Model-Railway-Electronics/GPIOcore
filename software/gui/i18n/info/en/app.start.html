Getting started

This program sets up a GPIOcore board: a small Arduino (Nano / Uno, or a DCCnext) that sits under your layout and switches things: turnouts, lights, signals, relays. You tell the board what is connected to which pin, and what should make it move.

The two kinds of things

  • Outputs (middle, right column) are things the board does: move a servo, pulse a turnout coil, light an LED, switch a relay. There are 16 of them.
  • Inputs (middle, left column) are things that tell the board to do something: a push button on your control panel, or a command from your DCC command station (your digital system / handheld). There are 16.

The settings of the selected input are always on the left, those of the selected output on the right.

Three modes: the coloured buttons at the top

  • ● Configure: change things. Offline, or connected (red frame): then every change goes to the board straight away.
  • ● Simulate (yellow frame): try your settings on a pretend board, press the buttons on the inputs and watch the outputs. Nothing can be changed here.
  • ● Live test (green frame): connects by itself; press the buttons and see what the real board does. Nothing can be changed here.

Connect / Disconnect next to the port shows whether a board is connected.

Step by step

  1. Connect. Plug the board into the USB port, choose its port at the top (it usually says CH340, USB Serial or Arduino) and click Connect. Use Read board to load what is on it. The first time, the program asks for a name for the board.
  2. Add an output. Click + Add output, or click an output. Choose the type (for example Servo) and the pin where the wire goes.
  3. Add an input. Click + Add input, or click an input. Choose what starts it: a button pin, a DCC address, or both.
  4. Connect them. Drag the output onto the input. A coloured line appears: that input now operates that output. The output gets the colour of its input.
  5. Try it. Click ● Live test and press the buttons on the input.
  6. Save (Ctrl+S) the configuration in a file; the program does not save by itself.

Good to know

  • Every (i) button explains the thing next to it.
  • Give inputs and outputs a name (field at the top of each panel). Names and all settings are kept on this computer in Documents\GPIOcore\boards\<board name>.json, one file per board.
  • A pin that is already used shows red in the pin list. If you choose it anyway, the input or output that had it becomes not in use.
  • Unused inputs and outputs are hidden; View → Show unused inputs and outputs shows them all.
  • View → Beginner / Advanced / Expert decides how much the program offers; it starts at Beginner and never changes your configuration. View → Theme switches to dark.
  • The Pin map tab (next to Configuration) shows which pin is used by what.
  • Board → Flash firmware… puts new firmware on the Arduino.
