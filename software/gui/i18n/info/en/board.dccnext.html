Board type

The board type decides which pins the program offers and what they are called.

  • Arduino Nano: pins D3–D12 and A0–A5, D0 / D1 from the Advanced level on, and A6 (analog input only).
  • Arduino Uno: as the Nano, but without A6 and A7.
  • DCCnext (by ArCoMoRa): a ready-made board with DCC input and screw terminals. The program uses the port numbers P1–P16 printed on the board everywhere: in the pin lists (“P1 (D3)”), on the canvas, on the pin map and in warnings. Only these 16 ports are offered: no D0, D1, D2, D13, A6 or A7.
  • Jack of all trades: our own board.
DCCnext portP1–P10P11–P16
Arduino pinD3–D12A0–A5

D2 (DCC) and D13 (config LED) are reserved on every board. The config button (A7) only exists on the Nano: an Uno and a DCCnext have no config button. Dimming (PWM) works on D3, D5, D6, D9, D10 and D11 (DCCnext P1, P3, P4, P7, P8 and P9).

A file made for another board type keeps all its pins. A pin this board does not have is shown with a warning, like any other pin that cannot be used: choose another pin for it.
