D0 and D1: the serial line

D0 (RX) and D1 (TX) are never an input or output pin: they are the board's serial line. Four things can use it: this program (over USB or Bluetooth), the board link to other boards, a DFPlayer on TX, and an HC-05 Bluetooth module.

  • When the board starts, it waits 5 seconds for this program. If the program connects, the line is the program's while you configure: the board link and the DFPlayer do nothing then.
  • If nothing connects (normal operation on the layout), the line becomes the board link (9600 baud): what comes in on RX is passed on to TX and runs as a DCC command; board link outputs and a DFPlayer use TX.
  • Board setting "D0 / D1 as inputs and outputs" (Advanced level): then D0 and D1 are normal pins when no program is connected, for example to pass a detector to the next board (high / low, through an optocoupler). The board link is off then.
  • Opening the USB port resets the board, so the program connects within those 5 seconds. Over Bluetooth there is no reset: press the config button briefly, then the line is the program's again for 5 seconds.
