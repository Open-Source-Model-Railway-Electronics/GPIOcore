Pins D0 and D1

D0 and D1 are the wires the Arduino uses to talk to this program over USB. Newer boards can still use them for your layout:

  • When the board starts, it waits 5 seconds for this program.
  • If the program connects, D0 / D1 stay reserved for USB while you configure. Things on those pins do not work then.
  • If nothing connects (normal operation on the layout), D0 / D1 become normal pins.
  • A brief press on the config button (Nano) makes them USB wires again for 5 seconds, so the program can connect without a reset.

Use them for simple things like LEDs. Avoid heavy loads on D0: they can disturb uploading new firmware.
