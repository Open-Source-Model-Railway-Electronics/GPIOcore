Sound effect: a DFPlayer Mini MP3 player

This output plays MP3 files from the micro SD card in a DFPlayer Mini module: a bell, a whistle, an announcement.

  D1 (TX) ---[1k]--- DFPlayer RX
  5 V -------------- DFPlayer VCC
  GND -------------- DFPlayer GND
  speaker (3 W max.) DFPlayer SPK_1 / SPK_2
  • The 1 kΩ resistor in the TX line protects the DFPlayer; nothing goes back to the Arduino.
  • Files on the SD card: 0001.mp3, 0002.mp3 … Track 1 is 0001.mp3.
  • The input chooses the track, so one sound output can play many sounds: give a toggle or absolute input Custom values (a track for off and one for on), use a route step, or send a DCC extended value. Track 0 = stop. Without custom values: on = track 1, off = stop.
  • An input you connect to a sound output gets custom values by itself: off = stop, on = track 1.
  • Several sound outputs may use D1 together, but one is usually enough.
  • Only without a PC: D1 is also the USB line to the computer. With the GUI connected the board only reports the track (♪ on the canvas). Unplug the USB cable and power the board otherwise to hear it.
  • Hear it on the PC (Advanced level and up): View > Sound folder… chooses a folder with the same files as the SD card (0001.mp3 …; 001.mp3, 1.mp3 and .wav work too). In Simulate and Live test the program then plays the track the board reports; a new track interrupts the previous one, like the DFPlayer. View > Mute sounds silences it.
  • Not on a DCCnext: it has no D1 on its terminals, so this type is not offered there.
