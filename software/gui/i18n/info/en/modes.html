Configure, Simulate and Live test

The program is always in one of three modes: the coloured buttons at the top. The connection is separate: Connect / Disconnect next to the port, with the state shown beside it (Offline, Connected: name, Simulation).

ModeFrameWhat you can do
● Configurenone offline, red when connectedChange everything. Offline you prepare a board; connected, every change goes to the board at once. Nothing is read from the board automatically: use Read board or Write all.
● SimulateyellowYour configuration runs on a pretend board. Press the input buttons and watch; nothing can be changed.
● Live testgreen when connectedConnects by itself. Press the input buttons and watch what the real board does; nothing can be changed. If the board has another name than the screen, the program offers to read the board first.

Nothing is saved to a file by itself: Save (Ctrl+S) always asks where, and closing the program asks about unsaved changes.

The input buttons

  • ◀ / ▶ (absolute inputs): ◀ = curved / off, ▶ = straight / on.
  • ▶ press (toggle) and ▶ start (route): like pressing the button or sending a DCC command.
  • aspect ▾ / value ▾: for an input that drives a signal or a PWM output. Choose per lamp off, on, flashing or flashing in opposite phase.

A button acts like a DCC command: a second click within half a second is ignored, just like a repeated packet from a command station.

What the outputs show

  • Blue dot = straight / on, red dot = curved / off, grey = not known yet.
  • Servo: a dial with the angle; it turns degree by degree as the board reports it.
  • Signal: four lamps in their colours, flashing like on the board.
  • Frog relays: a small relay drawing. The arm and the frog show which contact is live (red = curved, blue = straight). An electrofrog is grey (dead) while the turnout moves; a unifrog flips over at once.

Nothing needs to be connected to the board for a live test: you see what the board would switch.
