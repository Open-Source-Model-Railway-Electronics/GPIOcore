Block signal

Expert level (View menu).

A block signal sets itself, without a command station or computer. The board looks at two block detectors (inputs) every 50 ms and shows one of three aspects:

  • Unsafe — when the detector of its own block reports a train (usually red),
  • Caution — when its own block is free but the next block is occupied (usually yellow),
  • Safe — when both blocks are free (usually green).

Each aspect is chosen lamp by lamp with ▾, like a route step: every lamp can be off, on or flashing. Flashing lamps flash at 1 Hz. The lamps are on pins A–D; only pin A is required, so a signal with two or three lamps simply leaves the other pins at “not used”.

A detector is any input that is in use and has a pin: best a Sensor (occupancy) input, for example a current detector, a reed contact or a light barrier (pressed = LOW = occupied), or an analog condition. One detector may drive several signals.

The aspect is only computed, never stored. Inputs, routes and DCC commands cannot set a block signal, so it cannot be chosen as a target in the input panel and an input cannot be dragged onto it.

Example 1: Dutch 3-aspect signals in a row

Lamps: A green, B yellow, C red. Signal 1 protects block 1 (own block = its detector) and looks at block 2 (next block), signal 2 protects block 2 and looks at block 3, and so on. Aspects: unsafe = C on, caution = B on, safe = A on (the defaults). A train in block 2 gives signal 2 red, signal 1 yellow and signal 3 green.

Example 2: a main signal without a linked next block

Red / green only: leave Next block at “none”. Unsafe = red, safe = green; the caution aspect is not used.

Example 3: a distant signal

A distant signal stands in front of a main signal and announces what that main signal shows. Make it a block signal whose own block is the detector of the block behind the main signal ahead (the block that main signal protects), next block “none”: occupied = yellow (the main signal shows red), free = green. The main signal uses the same detector as its own block, so one detector drives both.

A block on the next board

The next block’s detector may be on another board. Wire its signal through an optocoupler to an input here, for example D0 (RX): on the board D0 only works when no PC is connected (5 s after power-up without the GUI); in the simulator it always works.
