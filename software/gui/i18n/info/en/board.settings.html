Board settings

  • Name: up to 16 letters, stored on the board. The program finds this board's file (names of inputs and outputs) by this name, so give every board its own name.
  • Board type: Arduino Nano, DCCnext or Jack of all trades. It decides which pins exist.
  • Own wait time per route step (Advanced level and up): off = every step waits the same time (set below) and routes need half the memory. On = each step has its own wait time.
  • Route interlocking (Advanced level and up): what happens when a route is started while another one is still running. Off = both run, on = the second one is ignored, automatic = routes that move a turnout run one at a time, routes with only lights may run together.

Pins with a fixed job on every board: D2 (DCC input and config button), D13 (config LED), and D0 / D1 (the serial line).
