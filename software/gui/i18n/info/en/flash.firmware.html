Updating the firmware

The firmware is the program that runs on the Arduino of your GPIOcore board. Sometimes there is a newer version with fixes or new features. This window puts it on your board.

Step by step

  1. Plug in the board with a USB cable.
  2. Port: choose the board. It usually says CH340, USB Serial or Arduino. Don't see it? Check the cable and click Refresh.
  3. Firmware file: this is the file with the new program (it ends in .hex). Normally the right file is already filled in. If not, click Browse… and pick GPIOcore.hex.
  4. Board type: most boards work with Arduino Uno / Nano (new bootloader). Cheaper or older Nano boards often need Arduino Nano (old bootloader). Not sure? Just start with the first one: if the board does not answer, the program tries the other one by itself.
  5. Click Flash and wait until the bar is full. This takes about 10 to 30 seconds. Do not unplug the board while it is busy.

Good to know

  • This program lets go of the board while uploading and connects again afterwards. You don't have to do anything.
  • Your settings on the board (outputs, inputs, connections) are normally kept. To be safe, use File → Save first.
  • Other programs that use the board, like the Arduino IDE serial monitor, must be closed first.
  • Something went wrong? Read the red message: it says what to try. Show details shows the full report, which is handy when you ask someone for help.
  • A failed upload does not break the board. Just try again.

Via ArduinoISP programmer (advanced)

Only for boards without a USB bootloader, or a board that no longer answers. You need a second Arduino running the ArduinoISP sketch, wired to the six ICSP pins of your board. Choose the port of that programmer Arduino. This also sets the chip settings (fuses) and removes the USB bootloader, so afterwards you can only update this board with the programmer. It also erases your settings on the board: save them with File → Save first, and write them back afterwards.
