Bluetooth (HC-05)

With an HC-05 Bluetooth module on the board you can configure it without a USB cable. The program sets the module up for you through the board (Board > Set up Bluetooth (HC-05), level Advanced or higher). Arduino Nano only: you need the config button to connect later.

Wiring (HC-05 → Nano):

  • VCC → 5 V, GND → GND.
  • RXD → D1 through a voltage divider: 1 kΩ from D1 to RXD, 2 kΩ from RXD to GND (the HC-05 takes 3.3 V on its RXD).
  • TXD → D0 through a Schottky diode (BAT85 or 1N5819), with the cathode (the stripe) at the HC-05 TXD. The diode lets the HC-05 pull D0 low but never fights the USB chip, so USB keeps working while the HC-05 is attached.

Setting it up (once):

  1. Hold the button on the HC-05 while you plug in the USB cable. Its LED now blinks slowly (about every 2 seconds): the module is in AT mode.
  2. Connect the program to the board over USB.
  3. Choose Board > Set up Bluetooth (HC-05) and click Start. The board tries the usual speeds and sets the module to 115200 baud and the name GPIOcore-<board name>. The PIN stays as it is. This takes a few seconds.
  4. Unplug the board and plug it in again, without holding the button.
  5. In the Windows Bluetooth settings pair GPIOcore… (PIN 1234, or 0000 on some modules). Windows creates a COM port for it (sometimes two: use the "outgoing" one). Choose that port in GPIOcore.

If it fails: the module is not in AT mode (fast blinking = normal mode), the wiring is wrong, or the diode is missing or the wrong way round. Other modules (HC-06, some clones) do not know these commands.

Connecting over Bluetooth: opening the Bluetooth COM port does not reset the board, and 5 seconds after start-up the board closes its serial port (D0/D1 become normal pins). So when you click Connect, the program shows "Waiting for the board — press its config button briefly". Press the config button (A7) briefly: the board opens its serial port again for 5 seconds and announces itself, and the program connects. The program waits up to 30 seconds for that.

While the program is connected, D0 and D1 belong to the serial port: do not use them for inputs or outputs on a board with an HC-05.
