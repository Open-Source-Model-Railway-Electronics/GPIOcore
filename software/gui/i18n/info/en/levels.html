User levels

View → Beginner / Advanced / Expert decides what the program offers. Start with Beginner and switch up when you need more. The level never changes or removes anything in your configuration.

LevelOutputsInputs and board
BeginnerServo, single / double steady, single / double pulseDirect control (toggle or absolute) with a button pin and / or a DCC address; routes with the board's fixed wait time. Board settings: name and board type.
Advanced+ light effects (flashing, swing light, fireplace, TL tube, welder), 4-aspect signal, PWM with fading, sound effect, frog relays+ analog inputs, custom values, “Route starts on”, D0 / D1, own wait time per route step and route interlocking
Expert+ automatic block signal, servo that follows a detector (semaphore arm)+ Sensor (occupancy) inputs

A configuration may use more than your level offers, for example a block signal in a file made by someone else. It is shown and works as usual (also in Simulate and Live test), but its settings are read-only: switch to the level named in the yellow line to change them.
