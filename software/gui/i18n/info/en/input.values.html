Custom values: more than on and off

Normally a toggle or absolute input switches its output to curved / off (0) or straight / on (1). With Custom values each of the two states sends its own value instead, just like a route step:

  • Servo — an angle, e.g. off = 45°, on = 135° (or curved / straight as usual).
  • 4-aspect signal — an aspect per state, chosen lamp by lamp with ▾.
  • PWM — a brightness per state, e.g. off = 20 (dimmed), on = 255.
  • Sound effect — a track per state; stop (0) stops playing. One sound output can play many tracks, each chosen by its own input.
  • Other outputs — curved or straight per state, for example the other way round.

Off / curved is used when the input's state becomes 0 (an absolute input: button pressed or a DCC 'curved' command), On / straight when it becomes 1. A toggle input alternates between the two.

The two values are stored as 2 steps in the input's route memory, so they count in the board's route total. DCC extended commands still send their own value. Needs firmware with protocol v2.

Connect an input to a sound output and custom values are switched on by themselves: off = stop, on = track 1.
