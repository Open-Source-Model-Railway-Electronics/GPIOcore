Analog inputs: a resistor ladder or a sensor

Instead of a button to GND, an analog pin (A0–A6) can measure a voltage: 0 = 0 V, 1023 = 5 V. The input counts as pressed while the value meets the condition, and then works exactly like a pressed button: toggle, absolute and routes all work.

  • Below a value — pressed below the threshold, released again 20 higher. For example a light sensor (LDR) that gets dark, or a single button.
  • Above a value — pressed above the threshold, released again 20 lower.
  • At a value — pressed within the threshold ± 10: one button of a resistor ladder. Several inputs can share one pin, each with its own value.

Resistor ladder: several buttons on one pin. A 10 kΩ resistor from 5 V to the pin keeps it at 1023 while nothing is pressed; each button connects the pin to GND through its own resistor, so every button gives a different value.

  5 V ---[10k]---+--- A0
                 +---------[ button 1 ]--- GND    about 0
                 +--[1k]---[ button 2 ]--- GND    about 93
                 +--[3k3]--[ button 3 ]--- GND    about 254
                 +--[10k]--[ button 4 ]--- GND    about 512

Read the real values: resistors have tolerances and contacts have resistance, so practice differs from theory. Connect the board, choose the input and watch Now: while you hold each button; Use this value takes it as the threshold. Keep at least about 40 between two buttons.

  • The threshold is stored in steps of 8. The board reads the pin every 50 ms and only reacts when two readings agree.
  • A6 and A7 exist on an Arduino Nano only.
  • In Simulate, click value ▾ on the input to type a value for its pin: every input on that pin reacts.
