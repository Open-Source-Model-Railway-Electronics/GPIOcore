New board wizard and next steps

File → New board wizard… (also offered in File → New board) sets up a board for you in five short pages. It only uses the basics, so everything it makes can be changed at the Beginner level.

  1. Board: Arduino Nano, Arduino Uno or DCCnext, and a name if you like.
  2. What do you want to control? How many turnouts with a servo, turnouts with two coils (a short pulse on one coil or the other), turnouts with a stall motor such as MP1 or Tortoise, lights and uncouplers. Every item gets an output of its own. If they need more pins than the board has, the page says so.
  3. How do you control them? With DCC: the items get turnout (accessory) addresses one after another, from the number you choose, or you leave them empty and set them yourself. With buttons: a push button per item (every press switches it over) or a switch per item (on / off). One choice for all items.
  4. Pins: in order from the first free pin (D3 on a Nano or Uno, P1 on a DCCnext; the outputs first, then the buttons), or leave them empty and choose them yourself.
  5. Summary: what you get. Finish replaces the configuration on screen; if it has work of your own in it, you are asked first.

Next steps

After the wizard a Next steps list appears above the canvas: what is still left to do, for example choosing pins, setting the end positions of the servos, entering the addresses in your command station or iTrain, wiring the buttons, trying it in Simulate and writing it to the board. Tick what you have done.

  • The ticks are kept in the board file: save it (Ctrl+S) and they are there next time.
  • The arrow folds the list away; ✕ closes it. File → Show next steps opens it again.
