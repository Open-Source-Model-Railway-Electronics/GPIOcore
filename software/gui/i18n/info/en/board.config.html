Config button (A7) and teaching servos with your throttle

Without a computer you can set the end positions of servos with the config button and your DCC throttle.

Wiring: a push button from A7 to GND, plus a 10 kΩ resistor from A7 to 5 V (A7 has no built-in pull-up). An LED with resistor on D13 shows the mode (most Arduinos already have one).

  1. Hold the config button for 2 seconds: the LED starts blinking. You are in config mode.
  2. Press it briefly: the next servo is selected and moves over, so you can see which one it is. Press again for the next servo.
  3. On your throttle select loco address 9999.
    • Turn the speed knob: the selected servo moves. The direction button decides which way, the knob how fast.
    • F1 = store this angle as curved, F2 = store it as straight.
    • F3 = move the servo over (to check), F5 = next servo.
    • F4 = invert the frog relays of the selected servo, for relay modules that switch on LOW. Every press switches between normal and inverted.
  4. Hold the config button for 2 seconds again: the LED stays on. Back to normal.

The new positions are stored at once. Connect the program later and it reads them back.

Because of this, D13 and A7 can never be used for inputs or outputs.
