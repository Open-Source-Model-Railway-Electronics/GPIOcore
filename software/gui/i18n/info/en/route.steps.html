Route steps

A route is a list of things to do, from top to bottom. Each line (step) sets one output and then waits a moment before the next step.

When does the route start?

When the button on the input pin is pressed, or on a DCC command for the input's address. Choose which DCC command under Route starts on:

  • any command: straight and curved both start it;
  • straight only or curved only: so two routes can share one address. Example, a level crossing on address 1: route A on curved only switches the lights on and closes the barriers, route B on straight only opens them again.

A command station repeats a command a few times; the route takes the first one.

The columns

  • Output: what this step operates.
  • Value: what the output should do:
    • turnout, light, relay: curved (0) or straight (1);
    • 4-aspect signal: an aspect number (0–255);
    • servo: curved, straight, or an exact angle between 10° and 170°;
    • PWM: a brightness / speed value 0–255.
  • Wait after: only when Own wait time per route step is on in the board settings; otherwise every step waits the board's fixed time (0.3 s by default).

How to make one

  1. Choose an output in the first line, or drag an output onto this input.
  2. Click + Add step (or drag again) for the next one.
  3. Use ▲ ▼ to change the order, and the bin to delete a step.

The same output may appear more than once, for example a servo that first goes to 45° and then to 135°.
