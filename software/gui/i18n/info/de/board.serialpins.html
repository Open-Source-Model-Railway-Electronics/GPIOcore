Pins D0 und D1

D0 und D1 sind die Leitungen, über die der Arduino per USB mit diesem Programm spricht. Neuere Platinen können sie trotzdem für Ihre Anlage nutzen:

  • Beim Start wartet die Platine 5 Sekunden auf dieses Programm.
  • Verbindet sich das Programm, bleiben D0 / D1 während der Konfiguration für USB reserviert. Was an diesen Pins hängt, funktioniert dann nicht.
  • Verbindet sich nichts (normaler Betrieb auf der Anlage), werden D0 / D1 normale Pins. Hängt nichts an D0 / D1 (kein Eingang oder Ausgang, kein Soundeffekt), bleiben sie USB-Leitungen: Das Programm kann sich jederzeit verbinden.
  • Ein kurzer Druck auf den Konfig-Taster (Nano) macht sie für 5 Sekunden wieder zu USB-Leitungen, sodass sich das Programm ohne Reset verbinden kann.

Nutzen Sie sie für einfache Dinge wie LEDs. Vermeiden Sie große Lasten an D0: Sie können das Hochladen neuer Firmware stören.
