Rückmeldung — ein Sensor, auf den der Rekorder wartet

Ein Rückmeldeeingang ist ein Gleissensor: ein Reedkontakt unter dem Gleis mit einem Magneten unter dem Zug, eine Lichtschranke oder ein Stromfühler. Er sagt der Platine: „hier ist ein Zug“.

Warum? Züge brauchen nicht immer genau gleich lange. Bei der Aufnahme wird der Moment gespeichert, in dem der Sensor auslöst. Bei der Wiedergabe hält die Platine an dieser Stelle an und wartet, bis der Sensor wieder auslöst. So bestimmt der Zug den Takt, nicht eine Uhr.

Rückmelde-ID: eine Nummer (0–15), um Sensoren zu unterscheiden. Geben Sie jedem Sensor eine eigene Nummer.

Anschließen wie einen Taster: Sensor zwischen Pin und GND.
