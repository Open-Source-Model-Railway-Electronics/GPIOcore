Was ist an diesem Ausgang angeschlossen?

  • Einfach Dauer — ein Pin ein oder aus. LEDs, ein Relaismodul, Lampen (über einen Transistor oder ein Relais).
  • Einfach Impuls — ein Pin bekommt einen kurzen Impuls. Für ein Entkupplungsgleis oder ein Gerät mit einer Spule.
  • Einfach Blinken — ein Pin blinkt, solange er eingeschaltet ist. Ein Warnlicht.
  • Doppelt Dauer — zwei Pins: A ein und B aus oder umgekehrt. Zweifarbige Signale, zwei Relais.
  • Doppelimpuls — zwei Pins, einer davon bekommt einen kurzen Impuls. Für Weichenantriebe mit Spulen (Peco, Roco, Fleischmann …): A = die eine Spule, B = die andere Spule.
  • Wechselblinken — zwei Pins blinken abwechselnd.
  • Wechsellicht — zwei Lichter abwechselnd mit einer Pause: Bahnübergangslichter.
  • Kaminfeuer / Leuchtstoffröhre / Schweißlicht — Lichteffekte: flackerndes Feuer, eine Leuchtstoffröhre, die flackernd angeht, Schweißblitze. (Kaminfeuer und Leuchtstoffröhre brauchen PWM-Pins.)
  • 4-begriffiges Signal — vier LEDs (grün, gelb, rot, weiß …), gestellt durch DCC-Signalbefehle oder eine Fahrstraße.
  • Servo — ein Modellbau-Servo als Weichenantrieb. Langsame, vorbildgerechte Bewegung.
  • PWM — eine Helligkeit für eine Lampe oder LED-Kette, wahlweise langsam überblendend (Tag und Nacht).
  • Blocksignal — ein automatisches Signal (Lampen A–D): Die Platine wählt das Signalbild selbst aus den Meldern des eigenen und des nächsten Blocks.
  • Soundeffekt — ein MP3-Player (DFPlayer Mini) an D1: eine Glocke, ein Pfiff, eine Durchsage. Der Eingang wählt den Titel. Spielt nur, wenn kein PC angeschlossen ist.
  • Nicht benutzt — nichts angeschlossen.

Wichtig bei Spulen: Ein Arduino-Pin kann eine Spule nicht direkt treiben. Verwenden Sie eine Treiberplatine (zum Beispiel einen ULN2803 oder ein MOSFET-Modul) zwischen Pin und Spule.
