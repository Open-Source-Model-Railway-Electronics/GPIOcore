Soundeffekt: ein DFPlayer Mini MP3-Player

Dieser Ausgang spielt MP3-Dateien von der microSD-Karte in einem DFPlayer-Mini-Modul ab: eine Glocke, ein Pfiff, eine Durchsage.

  D1 (TX) ---[1k]--- DFPlayer RX
  5 V -------------- DFPlayer VCC
  GND -------------- DFPlayer GND
  Lautsprecher (max. 3 W) DFPlayer SPK_1 / SPK_2
  • Der Widerstand von 1 kΩ in der TX-Leitung schützt den DFPlayer; zum Arduino geht nichts zurück.
  • Dateien auf der SD-Karte: in einem Ordner MP3, benannt 0001.mp3, 0002.mp3 … Titel 1 ist /MP3/0001.mp3. Es zählt der Name, nicht die Reihenfolge, in der Sie sie kopieren. Nur MP3, kein WAV.
  • Der Eingang wählt den Titel, so kann ein Sound-Ausgang viele Klänge abspielen: Geben Sie einem Eingang mit Umschalten oder Absolut Eigene Werte (einen Titel für aus und einen für ein), verwenden Sie einen Fahrstraßen-Schritt oder senden Sie einen DCC-extended-Wert. Titel 0 = Stopp. Ohne eigene Werte: ein = Titel 1, aus = Stopp.
  • Ein Eingang, den Sie mit einem Sound-Ausgang verbinden, bekommt von selbst eigene Werte: aus = Stopp, ein = Titel 1.
  • Mehrere Sound-Ausgänge dürfen D1 gemeinsam nutzen, meist reicht aber einer.
  • Nur ohne PC: D1 ist auch die USB-Leitung zum Computer. Ist die GUI verbunden, meldet die Platine nur den Titel (♪ auf der Arbeitsfläche). Ziehen Sie das USB-Kabel ab und versorgen Sie die Platine anders, um ihn zu hören.
  • Am PC hören (ab Stufe Fortgeschritten): Ansicht > Sound-Ordner… wählt einen Ordner mit denselben Dateien wie der MP3-Ordner auf der SD-Karte (0001.mp3 …). In Simulieren und Live-Test spielt das Programm dann den Titel ab, den die Platine meldet; ein neuer Titel unterbricht den vorherigen, wie beim DFPlayer. Ansicht > Sounds stummschalten schaltet ihn stumm.
  • Nicht auf einer DCCnext: Sie hat kein D1 an ihren Klemmen, deshalb wird dieser Typ dort nicht angeboten.
