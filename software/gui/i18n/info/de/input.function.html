Was macht dieser Eingang?

Ein Eingang ist etwas, das der Platine einen Befehl gibt. Wählen Sie, was passieren soll:

  • Direkt schalten — der Eingang bedient einen Ausgang. Beispiel: ein Taster auf Ihrem Stellpult für eine Weiche. Drücken, die Weiche stellt um.
  • Fahrstraße — der Eingang stellt mehrere Ausgänge nacheinander. Beispiel: ein Taster für „Gleis 3 in den Bahnhof“: Weiche 1 Gerade, Weiche 2 Abzweig, Signal auf Grün. Bis zu 16 Schritte.
  • Nicht benutzt — der Eingang tut nichts. Verwenden Sie das für Eingänge, die Sie nicht brauchen.

Tipp: Sie müssen hier nicht zuerst wählen. Ziehen Sie einen Ausgang auf einen unbenutzten Eingang, wird dieser automatisch „Direkt schalten“.
