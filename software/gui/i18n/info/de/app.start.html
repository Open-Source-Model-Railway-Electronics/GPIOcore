Erste Schritte

Dieses Programm richtet eine IOcore-Platine ein: einen kleinen Arduino (Nano oder ein DCCnext), der unter Ihrer Anlage sitzt und Dinge schaltet: Weichen, Beleuchtung, Signale, Relais. Sie sagen der Platine, was an welchem Pin angeschlossen ist und wodurch es sich bewegen soll.

Die zwei Arten

  • Ausgänge (Mitte, rechte Spalte) sind Dinge, die die Platine tut: einen Servo bewegen, einer Weichenspule einen Impuls geben, eine LED leuchten lassen, ein Relais schalten. Es gibt 16 davon.
  • Eingänge (Mitte, linke Spalte) sind Dinge, die der Platine einen Befehl geben: ein Taster auf Ihrem Stellpult oder ein Befehl Ihrer DCC-Zentrale (Ihr Digitalsystem / Handregler). Es gibt 16 davon.

Die Einstellungen des gewählten Eingangs stehen immer links, die des gewählten Ausgangs rechts.

Drei Modi: die farbigen Knöpfe oben

  • ● Konfigurieren: Dinge ändern. Offline oder verbunden (roter Rahmen): Dann geht jede Änderung sofort an die Platine.
  • ● Simulieren (gelber Rahmen): Probieren Sie Ihre Einstellungen auf einer simulierten Platine aus, drücken Sie die Tasten der Eingänge und beobachten Sie die Ausgänge. Hier kann nichts geändert werden.
  • ● Live-Test (grüner Rahmen): verbindet sich selbst; drücken Sie die Tasten und sehen Sie, was die echte Platine tut. Hier kann nichts geändert werden.

Verbinden / Trennen neben dem Port zeigt, ob eine Platine verbunden ist.

Der schnellste Start

Das Programm startet mit einer leeren Platine: ein Eingang (DCC-Adresse 1), der einen Ausgang (an D3) schaltet. Wählen Sie oben in der Liste Preset eine fertige Konfiguration (zum Beispiel 16 servos) und klicken Sie auf Anwenden, oder beginnen Sie mit einem Beispiel: Datei → Beispiel öffnen….

Schritt für Schritt

  1. Verbinden. Stecken Sie die Platine an den USB-Anschluss, wählen Sie oben ihren Port (meist steht CH340, USB Serial oder Arduino dabei) und klicken Sie auf Verbinden. Mit Platine lesen laden Sie, was darauf steht. Beim ersten Mal fragt das Programm nach einem Namen für die Platine.
  2. Einen Ausgang hinzufügen. Klicken Sie auf + Ausgang hinzufügen oder auf einen Ausgang. Wählen Sie den Typ (zum Beispiel Servo) und den Pin, an dem der Draht hängt.
  3. Einen Eingang hinzufügen. Klicken Sie auf + Eingang hinzufügen oder auf einen Eingang. Wählen Sie, was ihn auslöst: einen Taster-Pin, eine DCC-Adresse oder beides.
  4. Verbinden Sie beide. Ziehen Sie den Ausgang auf den Eingang. Eine farbige Linie erscheint: Dieser Eingang bedient jetzt diesen Ausgang. Der Ausgang bekommt die Farbe seines Eingangs.
  5. Ausprobieren. Klicken Sie auf ● Live-Test und drücken Sie die Tasten am Eingang.
  6. Speichern (Ctrl+S) Sie die Konfiguration in einer Datei; das Programm speichert nicht von selbst.

Gut zu wissen

  • Jeder (i)-Knopf erklärt, was daneben steht.
  • Geben Sie Eingängen und Ausgängen einen Namen (Eingabefeld oben in jedem Bereich). Namen und alle Einstellungen werden auf diesem Computer in Dokumente\IOcore\boards\<Name der Platine>.json gespeichert, eine Datei pro Platine.
  • Ein bereits belegter Pin erscheint in der Pinliste rot. Wählen Sie ihn trotzdem, behält der Eingang oder Ausgang, der ihn hatte, seine Funktion, verliert aber diesen Pin.
  • Unbenutzte Eingänge und Ausgänge sind ausgeblendet; Ansicht → Unbenutzte Eingänge und Ausgänge anzeigen zeigt alle.
  • Ansicht → Anfänger / Fortgeschritten / Experte bestimmt, wie viel das Programm anbietet; es beginnt bei Anfänger und ändert nie Ihre Konfiguration. Ansicht → Design schaltet auf dunkel um.
  • Datei → Exportieren… speichert einige Ihrer Ausgänge, Eingänge oder Platineneinstellungen in einer eigenen Datei (Ihr eigenes Beispiel); Datei → Importieren… fügt sie einer anderen Platine hinzu, unter denselben Nummern oder an freien Plätzen.
  • Platine → Firmware flashen… spielt neue Firmware auf den Arduino.
