Erste Schritte

Dieses Programm richtet eine GPIOcore-Platine ein: einen kleinen Arduino (Nano / Uno oder ein DCCnext), der unter Ihrer Anlage sitzt und Dinge schaltet: Weichen, Beleuchtung, Signale, Relais. Sie sagen der Platine, was an welchem Pin angeschlossen ist und wodurch es sich bewegen soll.

Die zwei Arten

  • Ausgänge (rechte Spalte) sind Dinge, die die Platine tut: einen Servo bewegen, einer Weichenspule einen Impuls geben, eine LED leuchten lassen, ein Relais schalten. Es gibt 16 davon.
  • Eingänge (linke Spalte) sind Dinge, die der Platine einen Befehl geben: ein Taster auf Ihrem Stellpult oder ein Befehl Ihrer DCC-Zentrale (Ihr Digitalsystem / Handregler). Es gibt 16 davon.

Schritt für Schritt

  1. Verbinden. Stecken Sie die Platine an den USB-Anschluss. Wählen Sie oben ihren Port (meist steht CH340, USB Serial oder Arduino dabei) und klicken Sie auf Verbinden. Keine Platine zur Hand? Klicken Sie auf Demo, um alles mit einer simulierten Platine auszuprobieren.
  2. Einen Ausgang einrichten. Klicken Sie rechts auf einen Ausgang. Von rechts fährt ein Feld herein. Wählen Sie den Typ (zum Beispiel Servo) und den Pin, an dem der Draht hängt.
  3. Einen Eingang einrichten. Klicken Sie links auf einen Eingang. Von links fährt ein Feld herein. Wählen Sie, was ihn auslöst: einen Taster-Pin, eine DCC-Adresse oder beides.
  4. Verbinden Sie beide. Ziehen Sie den Ausgang (rechts) auf den Eingang (links). Eine farbige Linie erscheint: dieser Eingang bedient jetzt diesen Ausgang. Der Ausgang bekommt die Farbe seines Eingangs, so sehen Sie auf einen Blick, was zusammengehört.
  5. An die Platine senden. Alles, was Sie geändert haben, bekommt einen orangen Punkt. Klicken Sie oben auf … Änderung(en) schreiben. Die Platine speichert es, auch ohne Strom.

Gut zu wissen

  • Jeder (i)-Knopf erklärt, was daneben steht. Klicken Sie darauf, wenn Sie unsicher sind.
  • Roter Text bedeutet, dass etwas nicht stimmt, zum Beispiel zwei Dinge am selben Pin.
  • Zustand 0 / 1 testen in einem Ausgangsfeld bewegt ihn sofort, so können Sie Ihre Verdrahtung prüfen.
  • Datei → Konfiguration speichern legt eine Kopie Ihrer Einstellungen auf dem Computer ab. Machen Sie das, bevor Sie experimentieren.
  • Durcheinander geraten? Verwerfen verwirft alles, was Sie noch nicht auf die Platine geschrieben haben.
