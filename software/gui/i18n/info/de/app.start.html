Erste Schritte

Dieses Programm richtet eine GPIOcore-Platine ein: einen kleinen Arduino (Nano / Uno oder ein DCCnext), der unter Ihrer Anlage sitzt und Dinge schaltet: Weichen, Beleuchtung, Signale, Relais. Sie sagen der Platine, was an welchem Pin angeschlossen ist und wodurch es sich bewegen soll.

Die zwei Arten

  • Ausgänge (Mitte, rechte Spalte) sind Dinge, die die Platine tut: einen Servo bewegen, einer Weichenspule einen Impuls geben, eine LED leuchten lassen, ein Relais schalten. Es gibt 16 davon.
  • Eingänge (Mitte, linke Spalte) sind Dinge, die der Platine einen Befehl geben: ein Taster auf Ihrem Stellpult oder ein Befehl Ihrer DCC-Zentrale (Ihr Digitalsystem / Handregler). Es gibt 16 davon.

Die Einstellungen des gewählten Eingangs stehen immer links, die des gewählten Ausgangs rechts.

Drei Arbeitsweisen: die farbigen Knöpfe oben

  • ● Konfigurieren (roter Rahmen): Verbindung zur Platine am gewählten Port. Alles, was Sie ändern, geht sofort an die Platine; es gibt keinen eigenen Speichern-Knopf.
  • ● Simulieren (gelber Rahmen): keine Platine nötig. Ihre eigenen Einstellungen laufen auf einer simulierten Platine; klicken Sie auf die Tasten der Eingänge und beobachten Sie die Ausgänge. Es kann nichts kaputtgehen.
  • ● Live-Test (grüner Rahmen): Klicken Sie an einer echten Platine auf die Tasten der Eingänge und sehen Sie, was die Platine tut, auch wenn noch nichts verdrahtet ist.

Schritt für Schritt

  1. Verbinden. Stecken Sie die Platine an den USB-Anschluss, wählen Sie oben ihren Port (meist steht CH340, USB Serial oder Arduino dabei) und klicken Sie auf ● Konfigurieren. Beim ersten Mal fragt das Programm nach einem Namen für die Platine.
  2. Einen Ausgang hinzufügen. Klicken Sie auf + Ausgang hinzufügen oder auf einen Ausgang. Wählen Sie den Typ (zum Beispiel Servo) und den Pin, an dem der Draht hängt.
  3. Einen Eingang hinzufügen. Klicken Sie auf + Eingang hinzufügen oder auf einen Eingang. Wählen Sie, was ihn auslöst: einen Taster-Pin, eine DCC-Adresse oder beides.
  4. Verbinden Sie beide. Ziehen Sie den Ausgang auf den Eingang. Eine farbige Linie erscheint: Dieser Eingang bedient jetzt diesen Ausgang. Der Ausgang bekommt die Farbe seines Eingangs.
  5. Ausprobieren. Klicken Sie auf ● Live-Test und drücken Sie die Tasten am Eingang.

Gut zu wissen

  • Jeder (i)-Knopf erklärt, was daneben steht.
  • Geben Sie Eingängen und Ausgängen einen Namen (Eingabefeld oben in jedem Bereich). Namen und alle Einstellungen werden auf diesem Computer in Dokumente\GPIOcore\boards\<Name der Platine>.json gespeichert, eine Datei pro Platine.
  • Ein bereits belegter Pin erscheint in der Pinliste rot. Wählen Sie ihn trotzdem, wird der Eingang oder Ausgang, der ihn hatte, nicht benutzt.
  • Unbenutzte Eingänge und Ausgänge sind ausgeblendet; Ansicht → Unbenutzte Eingänge und Ausgänge anzeigen zeigt alle.
  • Ansicht → Expertenmodus zeigt die Bytes, das serielle Protokoll und die Presets. Ansicht → Design schaltet auf dunkel um.
  • Platine → Firmware flashen… spielt neue Firmware auf den Arduino.
