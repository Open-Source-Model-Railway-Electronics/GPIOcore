Umschalten oder absolut?

Umschalten — jeder Tastendruck schaltet den Ausgang um: Gerade → Abzweig → Gerade …
Verwenden Sie das für einen einzelnen Taster (eine Taste, die beim Loslassen zurückfedert). Der Ausgang ändert sich in dem Moment, in dem Sie drücken, nicht beim Loslassen.
Bei DCC schaltet jeder Befehl an die Adresse ihn um.

Absolut — der Ausgang folgt dem Eingang, wie ein Lichtschalter.
Verwenden Sie das für einen Kippschalter (ein Schalter, der in seiner Stellung bleibt) oder für DCC: die Zentrale sagt dann „Gerade“ oder „Abzweig“ und der Ausgang macht genau das.
Mit einem Schalter: Kontakt geschlossen = Zustand 0 (Abzweig / aus), Kontakt offen = Zustand 1 (Gerade / ein).

Nicht sicher? Sie schalten per DCC vom Handregler oder aus einem Computerprogramm? Wählen Sie Absolut. Ein Taster auf einem Stellpult? Wählen Sie Umschalten.
