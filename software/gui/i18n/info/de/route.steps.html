Fahrstraßen-Schritte

Eine Fahrstraße ist eine Liste von Dingen, die von oben nach unten abgearbeitet werden. Jede Zeile (Schritt) stellt einen Ausgang und wartet dann kurz bis zum nächsten Schritt.

Wann startet die Fahrstraße?

Wenn der Taster am Eingangspin gedrückt wird, oder bei einem DCC-Befehl an die Adresse des Eingangs. Welcher DCC-Befehl, wählen Sie unter Fahrstraße startet bei:

  • jeder Befehl: Gerade und Abzweig starten sie beide;
  • nur Gerade oder nur Abzweig: So können sich zwei Fahrstraßen eine Adresse teilen. Beispiel, ein Bahnübergang auf Adresse 1: Fahrstraße A auf nur Abzweig schaltet die Lichter ein und schließt die Schranken, Fahrstraße B auf nur Gerade öffnet sie wieder.

Eine Zentrale wiederholt einen Befehl mehrmals; die Fahrstraße nimmt den ersten.

Die Spalten

  • Ausgang: was dieser Schritt bedient.
  • Wert: was der Ausgang tun soll:
    • Weiche, Licht, Relais: Abzweig (0) oder Gerade (1);
    • 4-begriffiges Signal: eine Signalbild-Nummer (0–255);
    • Servo: Abzweig, Gerade oder ein genauer Winkel zwischen 10° und 170°;
    • PWM: ein Helligkeits- / Geschwindigkeitswert 0–255.
  • Warten danach: nur wenn Eigene Wartezeit pro Fahrstraßen-Schritt in den Platineneinstellungen eingeschaltet ist; sonst wartet jeder Schritt die feste Zeit der Platine (Standard 0,3 s).

So legen Sie eine an

  1. Wählen Sie in der ersten Zeile einen Ausgang, oder ziehen Sie einen Ausgang auf diesen Eingang.
  2. Klicken Sie auf + Schritt hinzufügen (oder ziehen Sie erneut) für den nächsten.
  3. Mit ▲ ▼ ändern Sie die Reihenfolge, mit dem Papierkorb löschen Sie einen Schritt.

Derselbe Ausgang darf mehrmals vorkommen, zum Beispiel ein Servo, der erst auf 45° und dann auf 135° fährt.
