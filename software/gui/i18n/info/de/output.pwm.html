PWM: Helligkeit und Überblenden

Ein PWM-Ausgang dimmt eine Lampe oder eine LED-Kette an einem PWM-Pin (D3, D5, D6, D9, D10, D11): 0 = aus, 255 = volle Helligkeit. Verwenden Sie für mehr als etwa 20 mA einen Transistor oder ein MOSFET-Modul.

  • Tastgrad — die Helligkeit nach dem Einschalten, bis eigene Werte, ein Fahrstraßen-Schritt oder DCC extended eine andere setzen.
  • Überblendzeit — wie viele Sekunden eine volle Änderung von 0 auf 255 dauert; eine halbe Änderung dauert halb so lange. sofort (0) schaltet direkt um. Jede neue Helligkeit wird mit dieser Geschwindigkeit überblendet: aus eigenen Werten, einem Fahrstraßen-Schritt oder einem DCC-extended-Befehl. Beim Einschalten blendet der Ausgang aus dem Dunkeln auf.

Beispiel — Tag und Nacht: ein absoluter Eingang (ein Schalter oder eine DCC-Adresse) mit Eigene Werte aus = 0 und ein = 255 und einer Überblendzeit von 60 s. Das Umschalten auf Nacht dimmt das Licht in einer Minute; zurückschalten bringt den Tag genauso langsam zurück.
