DCC-Zubehöradresse

Ihre DCC-Zentrale kann auch Befehle an Zubehör wie Weichen senden. Jeder Zubehörartikel hat eine Nummer: seine Adresse.

Setzen Sie hier den Haken und geben Sie die Adresse ein, die Sie an Ihrem Handregler oder in Ihrem Computerprogramm verwenden (zum Beispiel 12). Schaltet die Zentrale die Adresse 12, reagiert dieser Eingang.

  • Absolut: „Gerade“ und „Abzweig“ stellen den Ausgang.
  • Umschalten: Jeder Befehl schaltet den Ausgang um.
  • Fahrstraße: jeder Befehl, oder nur „Gerade“ / nur „Abzweig“ (siehe die Einstellungen der Fahrstraße).

Eine Zentrale sendet jeden Befehl mehrmals. Ein Umschalt-Eingang und eine Fahrstraße nehmen den ersten und ignorieren dieselbe Adresse danach eine halbe Sekunde lang, damit ein Umschalt-Eingang nicht zurückspringt.

Häufiger Fehler: Zwei Eingänge mit derselben Adresse reagieren beide. Das kann gewollt sein (zwei Fahrstraßen auf einer Adresse), meistens ist es aber ein Tippfehler.

Kein DCC? Lassen Sie den Haken weg und verwenden Sie nur einen Pin.
