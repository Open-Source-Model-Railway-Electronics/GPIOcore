PWM: brilho e transição

Uma saída PWM regula a intensidade de uma lâmpada ou fita de LEDs num pino PWM (D3, D5, D6, D9, D10, D11): 0 = apagado, 255 = brilho máximo. Use um módulo com transístor ou MOSFET para mais de cerca de 20 mA.

  • Ciclo de trabalho — o brilho após ligar a alimentação, até que valores próprios, um passo de itinerário ou DCC estendido definam outro.
  • Tempo de transição — quantos segundos demora uma mudança completa de 0 a 255; uma mudança de metade demora metade. de imediato (0) muda logo. Cada novo brilho transita a este ritmo: a partir de valores próprios, de um passo de itinerário ou de um comando DCC estendido. Ao ligar a alimentação a saída acende gradualmente a partir do escuro.

Exemplo — dia e noite: uma entrada Absoluto (um interruptor, ou um endereço DCC) com Valores próprios desligado = 0 e ligado = 255, e um tempo de transição de 60 s. Mudar para noite atenua as luzes num minuto; voltar traz o dia igualmente devagar.
