O que faz esta entrada?

Uma entrada é algo que dá um comando à placa. Escolha o que deve acontecer:

  • Controlo directo — a entrada comanda uma saída. Exemplo: um botão de pressão no seu painel de comando para uma agulha. Prime-o, a agulha muda.
  • Itinerário — a entrada define várias saídas, uma após a outra. Exemplo: um botão para “via 3 para a estação”: agulha 1 directo, agulha 2 desviado, sinal a verde. Até 16 passos.
  • Sensor (ocupação) — um detector de ocupação ou outro sensor. Não comuta nada por si só; um sinal de bloco ou um servo usado como braço de semáforo lê-o para saber se o seu cantão está ocupado.
  • Não utilizado — a entrada não faz nada. Use isto para entradas de que não precisa.

Dica: não tem de escolher aqui primeiro. Arrastar uma saída para uma entrada não utilizada torna-a automaticamente “Controlo directo”.
