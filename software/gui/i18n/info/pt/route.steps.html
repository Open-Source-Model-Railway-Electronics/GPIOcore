Passos do itinerário

Um itinerário é uma lista de coisas a fazer, de cima para baixo. Cada linha (passo) define uma saída e depois espera um momento antes do passo seguinte.

Quando arranca o itinerário?

Quando o botão no pino de entrada é premido, ou com um comando DCC para o endereço da entrada. Escolha qual comando DCC em O itinerário arranca com:

  • qualquer comando: directo e desviado arrancam-no ambos;
  • só directo ou só desviado: assim dois itinerários podem partilhar um endereço. Exemplo, uma passagem de nível no endereço 1: o itinerário A em só desviado acende as luzes e fecha as cancelas, o itinerário B em só directo volta a abri-las.

Uma central repete um comando algumas vezes; o itinerário aceita o primeiro.

As colunas

  • Saída: o que este passo comanda.
  • Valor: o que a saída deve fazer:
    • agulha, luz, relé: desviado (0) ou directo (1);
    • sinal de 4 aspectos: um número de aspecto (0–255);
    • servo: desviado, directo, ou um ângulo exacto entre 10° e 170°;
    • PWM: um valor de brilho / velocidade 0–255.
  • Esperar depois: só quando Tempo de espera próprio por passo do itinerário está ligado nas definições da placa; caso contrário cada passo espera o tempo fixo da placa (0,3 s por predefinição).

Como criar um

  1. Escolha uma saída na primeira linha, ou arraste uma saída para esta entrada.
  2. Clique em + Adicionar passo (ou arraste de novo) para o seguinte.
  3. Use ▲ ▼ para mudar a ordem, e o caixote do lixo para eliminar um passo.

A mesma saída pode aparecer mais de uma vez, por exemplo um servo que primeiro vai para 45° e depois para 135°.
