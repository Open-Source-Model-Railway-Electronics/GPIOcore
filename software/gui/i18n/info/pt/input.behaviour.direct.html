Comutar ou Absoluto?

Comutar — cada pressão inverte a saída: directo → desviado → directo …
Use isto para um único botão de pressão (um botão que volta atrás quando o larga). A saída muda no momento em que prime, não quando larga.
Com DCC cada comando para o endereço inverte-a.

Absoluto — a saída segue a entrada, como um interruptor de luz.
Use isto para um interruptor (um interruptor que fica onde o põe) ou para DCC: a central diz então “directo” ou “desviado” e a saída faz exactamente isso.
Com um interruptor: contacto fechado = estado 0 (desviado / desligado), contacto aberto = estado 1 (directo / ligado). Um interruptor que foi mudado com a alimentação desligada é seguido no arranque. Uma entrada Comutar não faz nada no arranque.

Não tem a certeza? Usa DCC a partir de um comando manual ou de um programa de computador? Escolha Absoluto. Um botão de pressão num painel? Escolha Comutar.
