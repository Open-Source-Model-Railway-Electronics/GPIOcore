Estado e teste

Cada saída tem um estado: 0 ou 1. O que isso significa depende da saída: para uma agulha 0 = desviado e 1 = directo; para uma luz 0 = desligado e 1 = ligado.

Estado guardado: a placa memoriza o último estado, também quando a alimentação está desligada. Depois de ligar, a saída volta a esse estado (excepto agulhas de bobinas: não recebem impulso ao ligar a alimentação, para que não disparem todas ao mesmo tempo).

Teste: desviado / desligado e Teste: directo / ligado enviam esta saída de imediato para a placa e comutam-na. Use isto para verificar as suas ligações: muda a agulha certa, no sentido certo? Se “directo” e “desviado” estiverem trocados, troque as duas posições (servo) ou os dois fios / pinos (motor de bobinas).
