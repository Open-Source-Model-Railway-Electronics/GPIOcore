Pinos D0 e D1

D0 e D1 são os fios que o Arduino usa para comunicar com este programa por USB. As placas mais recentes podem usá-los também para a sua maqueta:

  • Quando a placa arranca, espera 5 segundos por este programa.
  • Se o programa se ligar, D0 / D1 ficam reservados para o USB enquanto configura. O que estiver nesses pinos não funciona nessa altura.
  • Se nada se ligar (funcionamento normal na maqueta), D0 / D1 passam a ser pinos normais. Quando não há nada em D0 / D1 (nenhuma entrada ou saída, nenhum efeito sonoro), continuam a ser fios USB: o programa pode ligar-se a qualquer momento.
  • Uma pressão breve no botão de configuração (Nano) torna-os de novo fios USB durante 5 segundos, para que o programa se possa ligar sem reiniciar a placa.

Use-os para coisas simples, como LEDs. Evite cargas pesadas em D0: podem perturbar o carregamento de firmware novo.
